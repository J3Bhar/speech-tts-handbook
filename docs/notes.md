# Notes for readers

- The handbook is for teaching **general TTS methods**, not sharing a private experiment.
- Examples show concepts and configurable paths, not guaranteed drop-in commands for every software version.
- Public helper utilities are intended for **file and data checks**, not as full neural model implementations.
- Check each upstream recipe's current arguments and dependencies.
- Follow data usage rights and do not upload identifiable speech without permission.
- Keep private configurations, internal system details, checkpoints and training results in private storage.
